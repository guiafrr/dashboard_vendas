O desafio tem como objetivo a criação de um dashboard de vendas referente ao Xbox Games Pass, com foco total na organização e visualização de dados.

Para alcançar o objetivo proposto, dividimos a planilha em quatro partes:
  1 - Assets: aqui é destinado todos os recursos que utilizamos(como imagem e logos do xbox, escala de cores da mesma palheta do xbox)
  2 - Bases: aqui é onde inserimos os dados que foi extraido de um banco de dados(fictício).
  3 - Calculos: aqui é onde usamos a base de dados e realizamos cálculos, respondendo, assim, as perguntas de negócios atráves das tabelas dinâmicas.
  4 - Dashboard: aqui é o projeto tem seu foco principal. Organizanos os dados respondendo as perguntas de negócios atráves de tabalas dinâmicas, logo em seguida formatamos a tela inical da dashboard para uma fácil visualização e leitura do usuário              atráves de formas e segmentação de dados.

  Com o projeto finalizado, foi possível evidenciar a importância da transformação de dados brutos, em dados com visuais claros e úteis.
